# Javideo

本地番号影片刮削、磁力搜索、媒体库管理与字幕下载工具（Windows 桌面软件）。

## 功能一览

### 搜索与刮削

输入番号，自动从 MetaTube 刮削元数据（封面、标题、演员、简介、厂商、发行日期等），
搜索磁力链接，并获取 DMM 预告片（需代理）。刮削结果支持一键入库。

- 元数据翻译（接入 LLM 服务自动翻译标题与简介；元数据为空时自动跳过）
- 多候选源选择（同一番号有多个数据源时供用户挑选）
- **本地优先**：已入库的番号直接加载库内信息（封面、磁力、预告片全部走本地），不再重复刮削
- 刮削页演员头像按名字自动解析下载

### 媒体库管理

入库后的影片按媒体库组织，文件夹结构为：

```
{媒体库目录}/
  {番号}/
    poster.jpg         封面
    thumb.jpg          缩略图
    {番号}.nfo         Kodi 兼容的 nfo 元数据
    {原文件名}.mp4      入库的视频文件（保留原文件名，不重命名）
    {原文件名}.srt      字幕（可选，见「字幕下载」）
    磁力链接.txt        关联的磁力链接
```

- 支持多个媒体库 + **「全部」聚合视图**（所有库的入库内容，默认入口；侧边栏媒体库置顶）
- 扫描目录识别已下载的影片文件（mp4 / mkv / strm / avi / wmv / mov / ts / m4v），支持单个或批量入库
- **入库不重命名源文件**：视频按原文件名移入影片文件夹——刮削识别错误时，原文件名就是追溯真身的线索
- **番号识别增强**：
  - `FC2-PPV-4159520` 完整识别（不再截断）
  - 含数字的标签（`S2MBD-006`、`T28-058`）正确支持
  - 文件名状态标记自动转为标签：`-C`/`-CH` → 中文、`-U`/`-uncensored` → 无码修复、`-UC` → 两者、含 `4K` → 4K
- **分集归集**：`FC2-PPV-1550026_1/_2/_3` 识别为同一番号，入库时按原文件名一并收集进影片文件夹
- **跨库移动**：影片卡片右键直接移动到其他媒体库（移入网盘库时自动拆分：视频进网盘目录、元数据进本地缓存）
- **网盘库本地缓存**：媒体库可开启「元数据缓存到本地」——封面、nfo、预告片等全部写入本地缓存，
  视频留在网盘映射目录不搬动（入库时按原文件名记录位置），只有播放时才访问网盘
- **后台入库队列**：批量入库过程中切换页面不打断，回来继续看进度，失败可重试
- **卡片角标**：左上角显示是否有视频 / 是否有预告片（媒体库、全部、收藏、演员、标签页均生效，网盘库同样适用）

### 字幕下载

基于迅雷官方字幕接口（GCID 内容指纹匹配，无需登录）：

- 读取本地视频计算 GCID（结果缓存，同文件不重复计算），精确匹配对应字幕
- 按**本地视频真实时长**（原生解析 MP4/MKV 容器）与字幕时长接近度排序，无本地时长时回退刮削片长
- 字幕列表展示格式、语言、时长、名称，一键下载到影片文件夹并自动按视频命名（播放器自动加载）

### 收藏

三类收藏入口，集中管理常看内容：

- **影片** — 卡片网格展示（含角标），按最近收藏或番号排序，支持批量取消
- **标签** — 收藏常用标签快速筛选
- **演员** — 收藏关注的演员，卡片样式与演员页一致

### 演员

- 浏览演员信息与作品列表，支持搜索、分页、收藏
- 详情页展示生日、身高、三围、罩杯、血型等基本信息与相关作品
- **手动编辑演员**：刮削缺失演员时可手动添加、重命名、移除（重刮不丢失）
- 头像本地缓存：入库/首访时自动按名字解析下载，不依赖远程图站

### 标签

按以下维度浏览：**类型（Genre）**、**系列（Series）**、**厂商（Maker）**、**自定义标签**。
支持标准库与非标准库的标签聚合，自定义标签可重命名。

### 播放器

- 自定义播放器路径，未配置时使用系统默认播放器
- 入库影片可直接从详情页启动播放
- 预告片支持搜索页在线预览与详情页本地播放

### 设置

| 模块 | 功能 |
|------|------|
| 媒体库 | 新建/编辑/删除媒体库，管理扫描目录，可开启「元数据缓存到本地」（适合网盘映射目录） |
| MetaTube | 配置刮削服务地址、超时、连通性测试 |
| 基本设置 | 语言（中/英）、主题（深色/浅色）、关闭行为、调试模式 |
| 播放器 | 自定义播放器路径 |
| 网络代理 | 配置 HTTP 代理用于下载 DMM 预告片 |
| 数据导入导出 | 备份与恢复用户数据（导出为一致性快照，导入前自动留底） |

## 快速开始

1. 前往 [Releases](https://github.com/CowanNath/Javideo/releases) 下载最新版
2. 下载并运行 `Javideo_2.0.0_x64-setup.exe` 完成安装（已有用户可覆盖升级）
3. 从桌面快捷方式启动 Javideo
4. 首次使用前往「设置 → MetaTube」配置刮削服务地址
5. 在「设置 → 媒体库」新建媒体库
6. 回到搜索页搜索番号，刮削后入库即可

> 运行环境：Windows x64、Microsoft Edge WebView2、.NET 8 ASP.NET Core Runtime（x64）。
>
> 提示：
> - 若需刮削 DMM 预告片，请在「设置 → 网络代理」配置可用代理
> - 字幕下载无需任何配置，扫描入库后即可使用

## 架构

```
┌─────────────────────────────────────────────────────┐
│                    javideo.exe                       │
│  ┌──────────────────────────────────────────────┐   │
│  │         Tauri 壳 (Rust)                      │   │
│  │  - 启动 / 管理 worker 进程                    │   │
│  │  - 暴露 get_worker_url 给前端                │   │
│  └──────────────┬───────────────────────────────┘   │
│  ┌──────────────┴───────────────────────────────┐   │
│  │         Vue 3 前端                            │   │
│  │  - 搜索/收藏/演员/标签/媒体库/设置            │   │
│  │  - Pinia 状态管理 / UnoCSS 样式              │   │
│  └──────────────┬───────────────────────────────┘   │
│                 │ fetch (127.0.0.1:动态端口)         │
│  ┌──────────────┴───────────────────────────────┐   │
│  │    javideo-worker.exe (.NET 8 Kestrel)       │   │
│  │  - MetaTube 刮削客户端                       │   │
│  │  - 多源磁力搜索（Btdig / Nyaa / Yhg007）     │   │
│  │  - 字幕匹配（迅雷接口，GCID 内容指纹）       │   │
│  │  - SQLite 数据持久化（WAL 模式）             │   │
│  │  - NFO / 封面 / 缩略图 / 头像写入            │   │
│  │  - DMM 预告片下载（支持代理）                │   │
│  │  - AI 翻译服务                               │   │
│  └──────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

Worker 以 Tauri **sidecar** 方式启动，监听 `127.0.0.1:0`（系统分配端口），
启动后在 stdout 打印 `JAVIDEO_WORKER_PORT=12345`，Tauri 壳读取后暴露给前端。

## 数据来源

- **元数据刮削**：[MetaTube](https://github.com/metatube-community/metatube-sdk-go)（用户自填服务器地址）
- **磁力搜索**：Btdig / Nyaa / Yhg007（HTML 解析，预留 Pollack 接口）
- **预告片**：DMM 官方（需非日本 IP 或代理）
- **字幕**：迅雷字幕接口（GCID 内容指纹匹配，社区逆向公开，无需登录）
- **翻译**：接入 LLM API（需在设置中配置）
